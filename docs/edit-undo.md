# Accepted assistant edit undo

`POST /api/interview-practice/sessions/:id/undo-edit` accepts `requestId`, `expectedRevision` and `proposalId`. The authenticated owner can undo an accepted proposal while coding remains active. The server verifies its original snapshot and computes the exact accepted result. If current acknowledged files differ, undo is rejected rather than overwriting newer manual work or another edit. Paused/frozen/final attempts cannot undo.

Undo restores the complete verified pre-edit files through a new saved snapshot (or the existing snapshot for a no-op), appends the normal typed workspace-save event and records `undoneAt`/`undoSnapshotId` on the proposal. Its original accepted status, decision time, proposed files and all prior snapshots remain historical evidence. Reports distinguish accepted-then-undone assistance from suggestions never accepted. Nothing is rewritten in a frozen report/evidence manifest.

The command uses existing transactional CAS, admission and durable owner-scoped idempotency. An exact retry cannot apply the restoration twice or replace newer files; the browser does not regress to an older replayed revision. A fresh duplicate undo key is rejected after the recorded undo. Retained response copies and deleted-request markers follow existing recovery/retention policies. No provider or runner call is required.

The interface requires explicit confirmation and uses the same bounded pending-request recovery as other actions. Rejected/undone proposals remain viewable, and frozen attempts preserve provenance without an active undo control. Tests cover actual service restoration, stale work, frozen state, ownership, replay and evidence provenance; HTTP tests enforce owner, origin and strict input boundaries; seven browser fixtures cover the transport/confirmation states. The explicitly opted-in PostgreSQL case checks restart, immutable history and exact replay after newer work. Hosted SQL persistence and independent accessibility review remain their separate qualification gates.
