# Focused retest chronology

`isUnseenFocusedRetest` supplies an optional saved-history diagnostic, never skill evidence or a learning-improvement claim. A valid sequence is published evidence-linked feedback, a suggested self-reported drill for that observed gap, then a fresh completed task with an authored competency transfer. Family exposure, deleted-history limitations and default-off best-effort delivery remain as documented in [measurement.md](measurement.md).

Original report availability requires a strict session-bound `coaching.ready` event from the server/model. A report's `createdAt` alone is not publication proof. Corrections use their exact `coaching.corrected` report/source/generation/reason binding and explicit `correction.publishedAt`; correction metadata can establish publication if the corresponding event is absent. Where event and metadata clocks differ, the later time is used. The later of event `occurredAt` and `recordedAt` is used for both publication and drill completion. Unknown, malformed, duplicated, foreign, contradictory or out-of-order publication history supplies no diagnostic. This can omit legacy samples; it does not invent historical availability.

The report available before a drill must already suggest that exact authored drill and contain a usable evidence-linked `Developing` or `Needs work` finding in its competency. A generic drill completed while that competency was strong or unobserved cannot be retroactively focused by a later correction. A publication event must also precede the drill in the same session's event sequence. Timestamp ties are conservatively omitted rather than assumed to establish an earlier publication.

Transfer matching uses only report versions published before the new task starts. A later correction cannot create a prior gap or erase what feedback was available at that earlier point. A correction published after the drill but before the new task may remove the earlier gap, in which case the sequence no longer qualifies. The code does not mutate original reports, progression or learner evidence.

Focused regression fixtures cover valid original and corrected publication sequences, drill-before-report, future original publication despite an earlier generation timestamp, corrections published after retest start, corrected-event/metadata clock disagreement, missing/ambiguous publication and recorded-time bounds. These are synthetic policy fixtures, not actual learner outcomes, expert acceptance or deployment measurements.
